# Redline Garage 3D

A 3D drag racing and car tuning game that runs in the browser, built with Three.js.

- 7 original cars (no real brands), each with its own engine sound
- Garage with paint, wheels, spoiler and upgrades (engine, tires, turbo)
- Quarter-mile races on 3 tracks: City Nights, Ocean Drive, Desert Run
- Christmas tree start, nitro, chase and side cameras, crowds in the stands
- Generated engine sounds and background music (no audio files)

## Play

Open `index.html` in a browser, or turn on GitHub Pages for this repository
(Settings → Pages → Deploy from branch → main) and open the link it gives you.

## Controls

- Tap **GAS** (or the screen) when the light turns green, then **Nitro**
- Keyboard: Space for GAS and nitro, C to switch camera

## Before launch

`TEST_ALL` in `index.html` unlocks every car for free while testing. Set it to `false` for release.
